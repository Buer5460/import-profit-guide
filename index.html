一位深圳卖家最近发现：这个月卖了 5 万美金，按自己的算法应该赚 2 万多，实际到账只有 1.5 万。差的 5000 去哪了？

先给结论

多数人用的算法是「采购价 + 头程 + FBA 费，售价一减」。这个算法只覆盖了到仓前的成本，而实际扣的钱远不止这三项。

第一处：到仓成本本身就漏了

FOB 价到真实到仓成本通常差 30%–60%。你算的"头程"如果只是海运费，下面这些多半没算：

  • MPF 商品处理费——有最低费和上限，别按每个 SKU 重复套最低费
  • HMF 港口维护费——仅海运
  • 报关行费用——$150–400/票。卖 100 件就是 $1.5/件
  • 关税保证金（Customs Bond）
  • 内陆运输 + 仓储
  • 关税——中国原产多数品类还有 Section 301 附加层，不只基础税率
一个直观的算法
一票货 $150 报关费，卖 100 件 = 每件 $1.5。没算进去，就是每件白亏 $1.5。

第二处：销售端费用没归集

广告费、仓储费、退货、FBA 配送——这些是销售变动费用，不是进口成本，但直接影响利润。建议分两堆记：

到仓成本（进口环节）销售变动费用（销售环节）
采购 + 物流 + 关税 + 清关平台佣金 + 支付费 + FBA 配送 + 广告 + 退货损耗

分清楚之后，才算得出这个关键数字：

盈亏平衡售价 = (到仓成本 + 单件固定销售费用) / (1 - 销售费用率)

低于这个价，卖一件亏一件，销量越大亏得越多。

举个真实口径的例子

采购 8.00 + 运保 1.20 + 关税 2.00 + 清关 0.80 = 到仓 12.00
售价 19.90，销售变动费用 5.00
贡献利润 = 19.90 - 12.00 - 5.00 = 2.90
贡献利润率 = 2.90 / 19.90 = 14.57%

若关税涨到 2.80：
到仓 12.80 → 贡献利润 2.10 → 利润率 10.55%
卖出 1000 件，少赚 800.00

第三处：预留金和汇损（这块要单独走对账）

坦白说，预留金（Account Level Reserve）和汇损属于亚马逊后台结算侧数据，不是进口环节能算出来的。要去后台 Settlement Report 里导，或用 ERP 拉。

所以建议分两条线：

  1. 进口到仓 + 盈亏平衡 → 用成本测算工具
  2. 平台对账 → 导结算报告 / 上 ERP
混在一起算，永远对不上
这是很多人"账算不平"的根因——不是算错，是两类数据混在一个口径里。

顺带提醒：比算错更危险的是编码

供应商或货代给的 HTS 编码是最大的错误来源。有卖家 1,200 个 SKU 全用采购代理给的编码，跑了一遍发现 38% 被建议改用不同的 10 位码。

作为 FBA 卖家，你是 Importer of Record——罚款落在你自己的 EIN 上，亚马逊不帮你扛。CBP 重大过失罚则是 4 倍未付税额，且审查可追溯五年。

归类建议必须由持牌报关人确认。这一点任何工具都不能替你做。
